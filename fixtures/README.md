# Local golden-master evidence

Original private fixtures, scenario definitions and the SHA-256 manifest remain unchanged on the development machine. They are excluded from the public repository so held-out inputs and expected outputs are not published.

Visible recorded outputs are available here and in the dashboard snapshot. For a new local experiment, copy `scenarios.example.json` to `scenarios.json`, add your own independent private held-out scenarios, then run the recorder to create a new manifest. This is a new run, not a reproduction of the private historical test set.

Never regenerate the original evidence just to make a failing verification pass.
